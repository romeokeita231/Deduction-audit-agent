# 一台状态机，挂在 Deduction 上

Status: accepted

Dispute 不设独立状态机，只保留 `openedAt / closedAt / result` 三个字段；"争议进行中"就等价于 Deduction 处于 `DISPUTED`。因为一笔扣款同时最多一个进行中的争议（GLOSSARY 已定），第二台状态机是对同一件事的第二次记账，会逼我们持续回答"扣款是 X 的时候争议是 Y"这种翻译问题。

## Considered Options

- **两台状态机（Deduction 一台、Dispute 一台）**：表达上更"正"，适合争议可以并发、可重开、可分多次提交的场景。本项目已明确"同时最多一个进行中"，这个前提不成立。

## Consequences

- "终态拒绝任何转移"只需实现一次，ADR 0001 的"关闭后不可改写"自动成立。
- 赢率的分母必须从状态**历史**里算（曾进入 `DISPUTED` 且到达 `WON` / `LOST`），不能只看最终状态——只看最终态会把"从未争议过"的扣款混进来。
- 若将来放开"同一笔扣款可二次争议"（部分争议、败诉后复议），这个模型要重做。这是它唯一的硬约束，也是唯一的推翻条件。
