# 规则进 context，答案不进

Status: accepted

政策规则（POD 决定收货量、BOL 决定发货量、价格以生效区间为准……）放进 system prompt；oracle 的判定结果、标注标签、期望答案一律不进。评估由此测的是"能不能按政策把证据装起来并得出结论"，而不是"能不能猜中标注"。oracle 是独立实现的一份代码，M6 开工前冻结，此后不得因查看 Agent 输出而调整。

## Consequences

- 指标衡量的是**政策执行力**，不是专业判断力。README 必须这样写；否则"95% 的准确率"会被读成"它会像人一样判断"。
- 真正的判断力只在"无规则可裁"的冲突格上被测量，那里正确答案是 `INCONCLUSIVE`。这约 20 条是整个评估里唯一不能靠读 prompt 直接解出的部分。
- 规则进 prompt 之后，"自相矛盾·有规则可裁"那半格对会读 prompt 的模型应当接近满分。这不是缺陷，是基线——**不要把它当成果宣传**。
