# CI 跑评估管线，不跑模型

Status: accepted

CI 每次 push 用 fixture（固定的工具返回 + 固定的模型输出）跑 10 条，只验证"指标算得对、闸门会红"；真打 100 条模型的 `eval:live` 是手动 / 每夜任务，产出报告存档，不阻塞 merge。理由是 100 条 × 15 秒 ≈ 25 分钟，要 API key 和真金白银，而温度 0 也不保证跨模型版本可复现。

## Consequences

- **CI 绿灯不再代表"模型没有退化"。** 它只代表管线正确。这句话必须写进 README，否则 CI 徽章会被读成一个它不承担的含义。
- harness 的正确性被单独验证——这本来就是 CI 该管的事，而且指标代码的回归会比模型回归更早被发现。
- 需要一套 fixture 的录制/回放机制（约 2h），否则"固定模型输出"这件事没有落点。
